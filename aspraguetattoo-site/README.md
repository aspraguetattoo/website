# Aarron Sprague — artist site

Static one-page site. Black / grey / white. Mascot is the Ito-style pug.

## Pages / sections
- Hero + artist intro
- Work (links into Instagram posts + full profile)
- Healing / aftercare
- Booking
- Contact

## Put it online
Drop the whole folder on any static host:

- Netlify Drop or Cloudflare Pages: upload the folder
- GitHub Pages: push the folder and enable Pages on `index.html`
- The shop can also park it on a subdomain later

Do not rename `assets/pug-mascot.png` without updating `index.html`.
